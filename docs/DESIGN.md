# Intent design

The main app is quiet and spacious: forest green, mint accents, warm neutral surfaces, rounded 20–28 dp panels, and a restrained type hierarchy. The dashboard pairs a large combined-time readout with service status, two useful metrics, and a weekly chart. There are no guilt scores, arbitrary goals, streaks, or alarming dashboard colors.

Four bottom destinations remain reachable with one hand: Today, History, Apps, Settings. Intention editing is a child of Settings. Onboarding explains the purpose before permissions, discloses the actual data scope, and ends with Samsung background guidance. Setup can be deferred; the dashboard then shows an actionable incomplete status.

The warning intentionally differs from the app: pure black, red warning symbol and heading, a named destination, single-select answer cards, a disabled-until-selected Continue button, and an always-available exit. Its body scrolls independently of the actions. Landscape uses side-by-side explanation and choices; large text remains scrollable. It imposes no countdown or extra text entry.

The timer is a dark, narrow pill aligned below the top system inset at the end of the screen. It has tabular time, no interactive controls, and no touch target; all underlying touches pass through. Settings expose its vertical position and visibility.

History shows calendar totals with readable chart labels, a selected-day value, an equivalent daily list, and an explicit empty state. The app picker uses real installed icons and package identifiers, with immediate updates. Answer ordering uses labelled up/down controls, which remain usable without dragging or precise gestures.

Colors follow system light/dark mode. Content scrolls instead of assuming one screen height. Status and selection use text and semantics in addition to color. Standard Material touch targets and insets apply throughout.
